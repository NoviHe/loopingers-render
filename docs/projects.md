# Galeri Render

Menu Galeri Render khusus untuk hasil render Generate dan Batch Render. Daftar
memindai folder output aktif beserta semua subfolder batch, dan menyediakan
Buka Video, Buka Folder, serta Buka Thumbnail untuk setiap hasil.

Gunakan Refresh Hasil untuk memindai ulang. Lokasi output ditampilkan pada
halaman dan dapat diganti melalui Select Output Folder di Settings.
Hasil render tidak memerlukan file project desain JSON.

Fitur penyimpanan desain dihapus. File JSON yang pernah disimpan sebelumnya
tetap berada di lokasi aslinya, tetapi tidak lagi ditampilkan sebagai project.
